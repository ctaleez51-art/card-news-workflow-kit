# PRD — 학습 기록에서 블로그 초안

## 해결할 불편과 결과
하루 학습 기록에서 글감을 골라 블로그 초안을 쓰는 반복 작업을 줄인다. 결과는 문단마다 기록의 근거 절을 표시한 Markdown 초안이다. 앱은 외부 게시를 하지 않는다.

## 흐름
1. 사용자가 `daily/YYYY-MM-DD.md` 하나를 선택한다.
2. Claude Agent SDK가 기록을 읽고 주제 후보 3~5개와 각 후보의 근거 절을 제안한다. 근거가 부족하면 부족한 점만 보여 준다.
3. 사용자가 주제 하나와 길이(약 800/1,500/3,000자)를 선택한다.
4. Claude가 초안을 쓰고, 앱이 각 문단의 근거 절이 실제 기록에 있는지 확인한다. 없으면 `기록에 없음`을 표시한다.
5. `daily/발행목록.md`와 비슷한 주제를 후보에 표시해 중복 발행을 경고한다. 자동으로 후보를 제거하지 않는다.
6. 결과를 `outputs/{projectId}/draft-v{n}.md`에 저장하고 내려받게 한다.

## 완료 기준
정상 입력에서 후보·선택·초안·근거가 남는다. 자료 부족 입력에서는 초안을 만들지 않고 부족한 점을 보여 준다. 실패한 Claude 호출은 오류를 표시한다.
