# 결정

- 카드뉴스의 입력 → AI 판단 → 사람 선택 → 결과 → 검수 흐름을 재사용했다. 이미지 생성과 웹 검색은 학습 기록 초안에 필요하지 않아 뺐다.
- 입력은 파일명 형식과 실제 파일 존재를 서버에서 확인한다. 자유 경로를 받지 않는다.
- 발행 목록은 발행일과 기록일이 다르므로 날짜 범위를 사용하지 않는다. 후보 제목과 발행 목록의 주제 단어가 겹치면 `발행됨 가능성`을 표시한다. 이 비교는 오탐·누락 가능성이 있어 사람이 판단한다.
- 600자 미만 기록은 800자 초안을 뒷받침하기 어렵다고 보고 중단한다. Claude의 자료 부족 판단도 적용한다.
- 문단의 근거 절은 앱이 실제 절 제목과 대조한다. 절 안 문장의 의미까지 자동 검증하지는 못한다.
- 외부 발행은 범위에 넣지 않았다. 초안 파일만 로컬에 저장한다.
